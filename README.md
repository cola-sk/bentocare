# 伴学小账 (BentoCare)

> 陪伴孩子上学成长，清晰记录每一笔托管、午餐考勤与缺勤退费。

“伴学小账 (BentoCare)” 是一款面向家庭与小饭桌/校托场景的轻量移动端 H5 考勤与对账 Web 应用。专为解决家长记录孩子在校午餐、校外小饭桌、晚托班、校车接送等考勤，并自动核算**“按天计费 / 按月预付 + 缺勤退费”**的实际支出与退费结余。

---

## 🌟 核心特色与功能

1. **双计费模式与退费引擎**：
   - **按月预付 + 缺勤退费 (`PER_MONTH`)**：月初预付固定包月金额，标记请假/缺席时自动根据固定单日退费额或当月法定工作日均摊计算退款。
   - **按天计费 / 后付 (`PER_DAY`)**：出勤天数实时累加计费，缺席计 0 元。
   - **对账总览**：精准核算预付总额、缺勤应退总额、按天实耗、最终实际应付净额与退款差额结余。
2. **移动端 H5 考勤打卡日历**：
   - 月历与单日视图无缝切换，状态小圆点与标签直观可视化。
   - 支持一键“全出勤”、“一键全部请假”、出勤粒子反馈。
   - 请假理由备注（如发热生病、家庭出游、学校调休），对账单可溯源。
3. **精美账单长图与 CSV 导出**：
   - 一键生成高清对账单卡片长图，直接发送到微信、家长群或小饭桌老师。
   - 支持导出标准 CSV 明细表格（Excel 直接打开）。
4. **多孩与自定义项目管理**：
   - 支持家庭多孩子档案独立管理与快速切换。
   - 托管项目自由增删（支持自定义名称、图标、包月价、退费规则、单日价）。
5. **Vercel Postgres 云存储与本地离线双保险**：
   - 接入 Prisma ORM + Vercel Postgres，支持家庭成员多端实时同步。
   - 支持完备的 JSON 数据导入与导出备份。

## 🛠️ 本地启动与开发

```bash
# 1. 安装依赖
pnpm install

# 2. 生成 Prisma 客户端
pnpm prisma:generate

# 3. 启动本地开发服务
pnpm dev
```

在手机或浏览器中打开：`http://localhost:3000`

---

## 🚀 部署至 Vercel

1. 将代码推送到 GitHub 仓库。
2. 在 Vercel 控制台中导入该仓库。
3. 在 Vercel 项目的 **Storage** 标签页中点击 **Create Database -> Postgres** 并绑定到该项目。
4. Vercel 将自动注入 `POSTGRES_PRISMA_URL` 与 `POSTGRES_URL_NON_POOLING` 环境变量，自动完成部署。
